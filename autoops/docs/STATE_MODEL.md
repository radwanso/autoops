# STATE MODEL

## Overview

The AutoOps state object represents the complete runtime status of every monitored service.

Each service has its own state object that is updated every pipeline cycle.

The state is stored in:

```
autoops/data/state.json
```

Each service entry contains operational data, runtime analysis, decisions, and execution results.

---

## Basic Structure

Example:

{
    "nginx": {
        "service": "nginx",
        "status": "UP",
        "mode": "NORMAL",
        "risk": {
            "level": "LOW"
        },
        "behavior": {},
        "incident": {},
        "prediction": {},
        "strategy": "NORMAL",
        "decision": "OBSERVE"
    }
}

---

## Core Fields

### service

Service name.

Example:

```
"service": "nginx"
```

---

### status

Current runtime status.

Possible values:

- UP
- DOWN

---

### fail_count

Number of consecutive failures detected.

---

### restart_attempts

Number of recovery attempts.

---

### success_count

Number of successful recoveries.

---

### history

Service event history used by the intelligence modules.

---

### last_failure_time

Timestamp of the latest detected failure.

---

### last_fix_time

Timestamp of the latest successful recovery.

---

### profile

Service-specific configuration loaded from config.yaml.

Contains values such as:

- restart_threshold
- escalation_threshold
- cooldown
- criticality

---

## Intelligence Fields

The following fields are produced by the intelligence pipeline.

### behavior

Generated by:

```
behavior.py
```

Example:

```
{
    "unstable": false,
    "safe_to_restart": true
}
```

---

### risk

Generated by:

```
risk_engine.py
```

Example:

```
{
    "level": "LOW"
}
```

Possible values:

- LOW
- HIGH
- CRITICAL

---

### mode

Generated by:

```
mode_engine.py
```

Possible values:

- NORMAL
- RECOVERING
- UNSTABLE
- CRITICAL

---

### incident

Classification produced by classifier.py.

---

### prediction

Prediction engine output.

Contains future failure estimation.

---

### strategy

Strategy selected by strategy_engine.py.

---

### policy

Recovery policy evaluation.

---

### intent

High-level system intent.

---

### response_plan

Execution plan generated before recovery.

---

### cognitive_state

Aggregated intelligence object produced before the decision layer.

---

## Decision Fields

### decision

Final decision produced by decision.py.

Typical values:

- OBSERVE
- RESTART
- ESCALATE
- STABLE

---

### execution_result

Returned by the execution layer.

Contains the result of the performed action.

---

## Runtime Fields

The pipeline also injects temporary runtime information.

Examples:

- metrics
- is_running

These values are generated every pipeline cycle.

---

## System State

The file also contains a special object:

```
_system
```

This object stores global system information.

Example:

{
    "_system": {
        "metrics": {},
        "health": {}
    }
}
